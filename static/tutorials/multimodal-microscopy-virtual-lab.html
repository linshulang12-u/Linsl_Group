    数值模型说明（每个滑块都驱动这些模型）
    • 焦点：高斯光束近似，w₀ = 0.433·λ/NA_eff，z_R = π·w₀²·n/λ，n = 1.33。高 NA 矢量衍射未计入。
    • 后瞳填充：β = D_beam/D_BFP，NA_eff = NA·min(1, β)，透过率 T = 1 − exp(−2/β²)。
    • 样品：9 层薄层（z = −40…40 µm）。成分：荧光染料；胶原（每像素带纤维方向 φ）；第 5 章的免标记细胞（脂滴、蛋白、吸收颗粒、折射率边界）。每层贡献 = 成分密度 ⊗ 离焦光斑 × 权重。单光子权重 1；双光子、SHG、SRS 用 w/√2 光斑、权重 (w₀/w)²。SHG 按非相干叠加（简化）。
    • 脉冲：g = 0.664/(f·τ)；拔掉预补偿后 τ' = τ·√(1+(4ln2·GDD/τ²)²)，GDD = 6000 fs²。
    • 染料 σ₂(λ)：中心 920 nm、FWHM 120 nm 的高斯形示例谱；饱和 s = 1/(1+X/X_sat)（示例参数）。
    • SHG 偏振：I ∝ (cos²Δ + ρ sin²Δ)² + ρ² sin²2Δ；光谱：SHG 为 λ/2 窄线；每个通道 = ∫ 发射谱 × 透过率。
    • SRS：拉曼位移 Ω = 10⁷/λ_p − 10⁷/1040 cm⁻¹。ΔI_p/I_p = G·P_S·(w_ref/w₀)²·Σ K_s E_s·η_overlap，K_s = 拉曼谱（示例洛伦兹线）对激发带宽的平均。变换极限脉冲：激发带宽 Γ = √2·14.7/τ[ps] cm⁻¹，与延时无关；光谱聚焦（玻璃棒啁啾）：Γ = 25 cm⁻¹，中心随延时移动 60 cm⁻¹/ps，重叠宽度 2.8 ps（示例参数）。
    • 噪声：相对噪声谱密度 n(f)² = RIN(f) + 2e/I_DC + (i_amp/I_DC)²，RIN(f) = a·(1 kHz/f) + b（两种激光的示例曲线），I_DC = 0.25 A/W × P_p。每像素噪声 = n(f_mod)·√(1/2τ_dwell)，再经锁相时间常数 τ_LI 低通；每像素调制周期 f·τ_dwell < 1 时噪声按 1/(f·τ_dwell) 放大。直流探测：在 1/T_frame 到 1/(2τ_dwell) 之间积分噪声谱，并叠加样品折射率边界造成的透射变化（~3×10⁻³，示例）。
    • I/Q：锁相输出 Z = m·S·e^{iφ_e} + m·A_PT·e^{i(φ_e − φ_PT)}，φ_e = 360°·f·25 ns（电子学延迟），光热背景低通 A_PT ∝ 1/√(1+(2πfτ_th)²)、相位滞后 φ_PT = atan(2πfτ_th)，τ_th = 0.1 µs（示例）。X = Re(Z e^{−iφ_ref})，Y = Im(Z e^{−iφ_ref})。
    • 采集：泊松噪声 + 暗计数（PMT 通道）或高斯噪声（光电二极管 + 锁相）；一阶低通；振镜相位滞后与行校正。
